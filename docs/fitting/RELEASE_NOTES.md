## 已知限制

1. 仅支持配置中的两份 USDZ，不是通用任意模型的自动逆向软件。
2. 误差相对于 USDZ 有效数据，不保证实物制造或配合精度。
3. 只交付侧壁中段，排除顶面/底面过渡及圆形底座。
4. 开孔从拟合中排除，红色孔边界单独交付；参考侧壁未实体裁孔，也没有厚度/孔壁/倒角。
5. 严格对称和正方形是先验；mini 切点触及搜索下界，不能宣称已确定真实 CAD 切点。
6. 单调性、最近距离等部分检查基于密采样；不同高度仍共享同一源网格。
7. 公称宽度版只校准水平尺寸，竖向为保留侧壁区域的源高度，不是整机高度。
8. 验证环境为本机 Windows + Python 3.14.3；其他平台未验收。
