# 拟合参考的范围与结果

拟合参考以配置中的两份 USDZ 为观测输入，包含冻结轮廓、中段侧壁及数值验收数据。完整实体及三格式交付见 [项目 README](../../README.md)。

## 拟合参考内容

- 独立的 Python 包、统一 CLI、模块职责与集中模型/筛选配置。
- 两份原始 USDZ、SHA-256 指纹和完整运行环境记录。
- 底座和上下各 10% 区域排除；mini 9 个、Studio 15 个开口/面板边界遮罩。
- 四候选比较、训练/验证/测试分离、G3 与 CAD 回读验证。
- 原尺度/公称尺度 3dm、中段侧壁、孔边界、控制点、JSON/CSV 和诊断图。
- 冻结拟合结果、只读验证和当前参考完整性清单。

## 结果基线

冻结轮廓通过数值回归，详细记录见各机型的验收 JSON。

## 已知限制

1. 仅支持配置中的两份 USDZ，不是通用任意模型的自动逆向软件。
2. 误差相对于 USDZ 有效数据，不保证实物制造或配合精度。
3. 拟合参考面仅覆盖侧壁中段，排除顶面/底面过渡及圆形底座。
4. 开孔从拟合中排除，红色孔边界单独交付；参考侧壁未实体裁孔，也没有厚度/孔壁/倒角。
5. 严格对称和正方形是先验；mini 切点触及搜索下界，不能宣称已确定真实 CAD 切点。
6. 单调性、最近距离等部分检查基于密采样；不同高度仍共享同一源网格。
7. 公称宽度版只校准水平尺寸，竖向为保留侧壁区域的源高度，不是整机高度。
8. 验证环境为本机 Windows + Python 3.14.3；其他平台未验收。
