# 复现与验收

## 最少需要哪些数据

只复现外轮廓，需要每款模型八个完整精度控制点、七次 Bernstein 公式、[0,1] 参数范围、顺时针四分之一旋转和连接直线。复现存储的 2/3 mm 内轮廓，还需要各自 39 个控制点、权重及完整节点向量。这些定义都在 [geometry_definition.json](geometry_definition.json) 中。

文件中的 `profiles` 分别包含 `mac-mini`、`mac-studio`。`outer` 为外角段；`inner` 的键 `2` 和 `3` 为内角段；`degree` 是次数，不是阶数；`knots` 为不同节点，`multiplicities` 为对应重数，展开后才是完整节点向量。`controls_mm` 按曲线方向排列，不能重新排序。`weights` 当前全部为 1，但复现器仍按一般有理表达式实现。

参数文件包含精确复现数据、CAD 发布标识和规范文件哈希。项目构建以 `data` 和正式母版参数为权威，文档参数通过来源哈希与当前交付绑定；模型更新后应同步生成并核验文档。

## 独立运行绘图脚本

把参数文件和 [reproduce_profiles.py](reproduce_profiles.py) 放在同一个目录，然后运行：

```powershell
python -B reproduce_profiles.py --out reproduced
```

这条命令只依赖 Python 标准库，不导入本项目的拟合器或 CAD 构建代码。脚本用 de Casteljau 算法求 Bézier 点，用齐次 de Boor 算法求 B 样条点，按四段角曲线加四段直线组合完整轮廓。它为两款机型分别输出一个 SVG 预览和外圈、2 mm 内圈、3 mm 内圈的 CSV。

提高 `--samples` 只提高预览折线与采样点的密度，不改变曲线公式。例如 `--samples 1001` 表示每个角段 1001 个样点。若把采样点导入其他软件后再次“拟合曲线”，就会引入新的拟合选择，不能宣称已经恢复同一控制定义。

## 生成保持控制定义的 Rhino 曲线

在可导入 `rhino3dm` 的 Python 环境中执行：

```powershell
python -B reproduce_profiles.py --out reproduced --rhino
```

该模式额外保存两个曲线专用 3DM，每个包含外轮廓及两种内轮廓。它直接写入七次 NURBS 的控制点、权重和节点，不经过采样点插值。曲线按八段 PolyCurve 保存，模型单位为毫米。

本项目的依赖保存在 `.vendor`，普通 Python 默认不会搜索该目录。在项目根目录的 PowerShell 中，可临时加入依赖路径后运行；结束时恢复原值：

```powershell
$docOriginalPythonPath = $env:PYTHONPATH
try {
    $env:PYTHONPATH = (Join-Path (Get-Location) '.vendor')
    python -B docs/technical/reproduce_profiles.py --out .tmp/reproduced-profiles --rhino
} finally {
    $env:PYTHONPATH = $docOriginalPythonPath
}
```

只生成 SVG 和 CSV 时不需要上述依赖设置。

对于 Rhino，次数 7 对应阶数 8。Rhino 的显式节点数组比完整数学节点向量少首尾各一项，所以脚本赋值使用 `full_knots[1:-1]`。这个存储约定只影响数组表达，不改变曲线。不要把次数写成 8，也不要把重复节点全部去掉后直接填入。

若使用其他 CAD 软件，选择能指定次数、节点、权重与控制点的 NURBS 导入方式。只提供“圆角半径”或“通过点拟合”选项的工具不能直接表达本项目的完整曲线定义。

## 本套公式如何核验

文档构建时不重新拟合，也不修改正式 CAD。核验包括：

1. 外控制点逐数值等于公共参数；内控制点和节点直接取自当前发布的规范支撑定义。
2. 独立脚本对外角段和内角段的计算与 SciPy B 样条及 OCCT 支撑曲线评价交叉比较。
3. 检查八段轮廓闭合、旋转关系、对角对称和端点 G3；检查可解析的控制点共线条件。
4. 曲线专用 3DM 写出并重新读取，核对八段结构、次数、控制点、节点和点值。
5. 文档图表中的拟合数字来自冻结报告，并明确原始尺度和公称尺度；正式 80 个 CAD 文件的哈希保持原值。

## 从公式到完整 CAD 的转换方案

程序先以曲线、平面、圆锥、圆柱及布尔边界建立 BREP，再冻结母版。规范数据提取支撑类型、控制点、节点、权重、解析参数、三维边、二维修剪曲线、方向和拓扑关联。

Rhino 由规范数据直接创建 BREP，保存 3DM 后重新打开。STEP 从同一规范数据重建，统一输出 `.stp` 并通过 OCCT 原生读取。STEP 使用 17 位有效数字，对样条裁剪采用等价代数表示，降低极短区间导入时退化的风险。

无孔系列的 X_T 使用 Rhino 原生 Parasolid 写出器。带接口壳体和底座经严格验收的 STEP 传递文件导入 SolidWorks 的 Parasolid 内核，再保存 X_T。装配复制两个已验收零件，保持恒等位置。最终 X_T 关闭重开后直接读取其原生支撑与拓扑，不用转回 STEP 的结果替代。

原生自动修复、分析修复和解析简化会受到控制，任务结束后恢复设置。原生检查组件在进程内执行，避免大量跨进程逐项调用；任务临时注册在结束后撤销。

## 母版边界对齐规则

母版边界对齐使用平面与挤出支撑的解析等参交线。操作范围限于符合条件的近似三维边及对应修剪数据，支撑曲面和 G3 控制点保持固定。

这一步在暂存母版上实施，要求边界全参数域偏差不超过输入边容差，保持支撑、G3 控制数据、顶点定义及规定的拓扑关联。完成对齐并验收的母版是三格式共同比较的冻结对象；转换过程直接使用这一完整定义。

`source_revision.json` 记录输入哈希、逐边偏差、容差及支撑和拓扑检查结果。全参数区间最大偏差采用数值求极值工具检查，不声称是区间算术证明。外轮廓控制点须与公共定义一致。

## 三种误差与各自的验收条件

| 类别 | 比较对象 | 当前量级或阈值 | 解释 |
|---|---|---|---|
| 源拟合残差 | 有效源网格采样与拟合曲线 | Mini 测试 RMS 约 0.031 mm；Studio 约 0.147 mm | 包含源离散化与形状假设影响 |
| 内偏移近似误差 | 存储的内 B 样条与理想法向偏移 | 当前约 $10^{-9}$ mm，构建目标 $10^{-6}$ mm | 以密采样评价，公差不等于严格区间上界 |
| 转换定义误差 | 最终格式的原生定义与冻结母版 | 几何 $10^{-7}$ mm，归一化参数 $10^{-11}$ | 不是源拟合精度或加工精度 |
| 指定 G3 接缝 | 原生曲线导数及相邻支撑 | 切向 $10^{-9}$；曲率 $10^{-8}$ /mm；曲率变化率 $10^{-8}$ /mm² | 位置另受原接缝边容差约束 |
| 设计尺寸 | 厚度、锥角、孔径、配合、孔口边距等 | 各设计审计中单独规定 | 不与格式比较阈值互换 |

原生验证允许代数等价的升阶、插结、参数反向及必要的等价分片，但必须保留完整几何定义与参数覆盖。仅比较体积、包围盒或少量点不能证明这件事。
