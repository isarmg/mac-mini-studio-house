# 源模型

本目录保存用户提供的两份 USDZ，作为轮廓拟合与源特征提取的输入。文件身份由以下 SHA-256 指纹确定。

| 文件 | SHA-256 |
|---|---|
| `mac-mini-silver.usdz` | `83c6bc7efd467ad658130d575b59a8fad2e1c833dbf326890475cb10630da047` |
| `mac-studio.usdz` | `e690c05495622e9988e6d182e85e8258afa90b0bb5ab5ed59a6957b350ecfebe` |

具体设备代际和原始下载来源未在本项目另行认证；文件名本身不能作为制造尺寸或版本证明。输入指纹也写入 `configs/models.json`，正式流程会核对它。
